# DocuVault

## 1. Project Idea

DocuVault is a personal and family document organization and expiry-management application.

The goal is to provide one organized place where users can store, categorize, search, and manage important personal and family documents.

---

## 2. Problem

People often have important documents stored in different places such as:

- Phone gallery
- Downloads folder
- WhatsApp
- Email
- Google Drive
- OneDrive
- Physical folders

As the number of documents increases, it becomes difficult to find a particular document when it is needed.

People may also forget important expiry dates for documents such as:

- Vehicle insurance
- Driving licence
- Passport
- Other documents or certificates that have an expiry date
- Product warranties

---

## 3. Proposed Solution

DocuVault will provide a centralized and organized system for managing personal and family documents.

Users will be able to:

- Upload documents
- Categorize documents
- Search for documents
- View documents
- Track document information
- Track expiry dates where applicable
- Receive reminders for documents that are about to expire

The application will focus on making documents easy to find and manage rather than simply storing files.

---

## 4. Target Users

The initial target users are:

- Students
- Individuals
- Families

The application should be useful for managing documents belonging to different members of a family.

For example:

Father → Mother + Children

Mother → Husband + Children

Child → Father + Mother + Siblings

Access to documents will eventually be controlled using permissions rather than automatically allowing every family member to access everything.

## 6. Main Goals

The main goals of DocuVault are:

1. Make important documents easier to find.
2. Organize documents based on their purpose.
3. Allow documents to be associated with family members.
4. Track expiry dates where applicable.
5. Remind users before important documents expire.
6. Protect documents using proper authentication and access control.
7. Build a useful application that can be tested by real users.

---

## 7. Why Build This Project?

Existing services such as Google Drive, OneDrive, and phone storage are good for storing files, but they do not specifically focus on personal document organization and expiry management.

DocuVault aims to provide a document-focused layer that makes important documents easier to organize, search, and manage.

The project will also be used as a learning project to understand real-world software development, including:

- Frontend development
- Backend development
- Databases
- Authentication
- Authorization
- File storage
- Search
- Notifications
- Security
- Git and GitHub
- Deployment

---

## 8. Project Vision

The initial version will be simple and focused on the core problem.

The application can later be expanded with features such as:

- Family management
- Document expiry reminders
- OCR
- Automatic document information extraction
- Automatic categorization
- Smart document search
- Better notification systems

Advanced features will only be added after the basic application is stable and useful.
